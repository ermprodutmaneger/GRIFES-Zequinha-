Pagamento

Payment Brick · Order API
Como este pagamento é processado (modo de teste)
  1. O Brick tokeniza o cartão no navegador usando a MP_PUBLIC_KEY de teste.
  2. O token + os itens são enviados ao backend em POST /api/orders.
  3. O backend recalcula o total e chama POST https://api.mercadopago.com/v1/orders com processing_mode: automatic e o MP_ACCESS_TOKEN de teste.
  4. A página de confirmação consulta GET /v1/orders/{id} para mostrar o status e o Pix/boleto.
