Como esta loja funciona

Checkout transparente, sem sair do site

Passo 1

Escolha as peças

Catálogo estático em Cloudflare Pages, carrinho no navegador (localStorage) e frete fictício calculado por CEP e peso — nada de transportadora real.

Passo 2

Informe os dados

Nome, e-mail, CPF e endereço no formulário do site. Os valores são sempre recalculados no servidor antes de virar total_amount.

Passo 3

Pague no Brick

O Payment Brick renderiza cartão, Pix e boleto. No envio, apenas o token do cartão vai para o backend, que cria a ordem na Orders API com o seu access token.

Passo 4

Veja a confirmação

A página de confirmação mostra status, QR Code do Pix, linha digitável do boleto e permite reconsultar o pedido em GET /v1/orders/{id}.

Pagamento em modo de teste As credenciais usadas são as de teste do Mercado Pago. Nenhum valor real é cobrado e os dados de cartão de teste são públicos. Configure MP_PUBLIC_KEY e MP_ACCESS_TOKEN nas variáveis de ambiente do Cloudflare Pages — o access token nunca é enviado ao navegador.
